# K-Nomad 웹사이트 개선 사양서

## 📋 개선점 개요

- [ ] 홈페이지와 인증 페이지 외 다른 페이지 전부 삭제
- [ ] 별점 평점 삭제하고 [좋아요], [싫어요] 버튼만 남기기
- [ ] 인증 및 프로필 관련 버튼 제외하고 내비게이션 다른 페이지로 이동하는 버튼 삭제
- [ ] 필터 정보 재설정 (예산, 지역, 환경, 최고 계절)
- [ ] 카드 구조 변경하여 필터 정보를 Key-Value로 표시
- [ ] 가짜 데이터 수정하여 각 도시별 필터 요소 추가
- [ ] 'TOP 추천 도시' 제목을 '도시 리스트'로 변경하고 좋아요 순서대로 나열
- [ ] 자세히 보기 버튼 삭제

## 🎯 필터 정보 사양

### 예산
- [ ] 100만원
- [ ] 100~200만원
- [ ] 200만원 이상

### 지역
- [ ] 전체
- [ ] 수도권
- [ ] 경상도
- [ ] 전라도
- [ ] 강원도
- [ ] 제주도
- [ ] 충청도

### 환경
- [ ] 자연친화
- [ ] 도심선호
- [ ] 카페작업
- [ ] 코워킹 필수

### 최고 계절
- [ ] 봄
- [ ] 여름
- [ ] 가을
- [ ] 겨울

## 🚀 Phase별 구현 계획

### ☑️ Phase 1: 페이지 구조 정리 및 내비게이션 간소화

**목표**: 홈페이지와 인증 페이지 외 불필요한 페이지 제거 및 내비게이션 메뉴 간소화를 통해 핵심 기능에 집중할 수 있는 기본 구조 확립

#### 수정/개선 기능
- [x] app/page.tsx에서 불필요한 섹션 컴포넌트 제거 (LiveActivity, Tools, Newsletter)
- [x] Header.tsx에서 도시탐색, 순위, 커뮤니티, 도구, 가이드, 문의 메뉴 제거
- [x] 인증 관련 버튼(로그인, 언어 설정)만 유지
- [x] 모바일 메뉴에서도 동일하게 불필요한 메뉴 제거
- [x] 검색 기능 유지

#### 검증/확인 기능
- [x] 홈페이지가 정상적으로 로드되는지 확인
- [x] Header에 로고, 검색, 언어, 로그인 버튼만 표시되는지 확인
- [x] 모바일 메뉴가 올바르게 작동하는지 확인
- [x] 로그인/회원가입 페이지 접근 가능한지 확인
- [x] 삭제된 컴포넌트로 인한 빌드 에러가 없는지 확인

---

### ☑️ Phase 2: 평점 시스템을 좋아요/싫어요 시스템으로 변경

**목표**: 별점 평점 시스템을 좋아요/싫어요 버튼으로 교체하고, 상호작용 시 시각적 피드백과 숫자 업데이트 기능 구현

#### 수정/개선 기능
- [x] PopularCities.tsx에서 Star 컴포넌트와 rating 표시 제거
- [x] 좋아요/싫어요 버튼 컴포넌트 추가 (Heart, ThumbsDown 아이콘 사용)
- [x] 도시 데이터에 likes, dislikes 필드 추가
- [x] 버튼 클릭 시 상태 변경 로직 구현
- [x] 클릭 상태에 따른 아이콘 색상 변경 (좋아요: 빨간색, 싫어요: 회색)
- [x] 클릭 시 숫자 증가/감소 애니메이션 효과

#### 검증/확인 기능
- [x] 좋아요 버튼 클릭 시 아이콘이 빨간색으로 변하는지 확인
- [x] 싫어요 버튼 클릭 시 아이콘이 회색으로 변하는지 확인
- [x] 버튼 클릭 시 해당 숫자가 올바르게 증가/감소하는지 확인
- [x] 동일 버튼 재클릭 시 토글 기능이 작동하는지 확인
- [x] 좋아요/싫어요 상호 배타적 동작 확인
- [x] 모든 도시 카드에서 기능이 정상 작동하는지 확인

---

**목표**: 기존 필터 카테고리를 요구사항에 맞는 예산, 지역, 환경, 최고 계절로 변경하고 선택 옵션 업데이트

#### 수정/개선 기능
- [x] QuickFilters.tsx의 filterCategories 데이터 교체
- [x] 예산 필터: 100만원, 100~200만원, 200만원 이상
- [x] 지역 필터: 전체, 수도권, 경상도, 전라도, 강원도, 제주도, 충청도
- [x] 환경 필터: 자연친화, 도심선호, 카페작업, 코워킹 필수
- [x] 최고 계절 필터: 봄, 여름, 가을, 겨울
- [x] 필터 UI 아이콘 및 스타일링 업데이트

#### 검증/확인 기능
- [x] 모든 새로운 필터 카테고리가 올바르게 표시되는지 확인
- [x] 각 필터 옵션 클릭 시 선택/해제가 정상 작동하는지 확인
- [x] 선택된 필터가 하단에 올바르게 표시되는지 확인
- [x] 초기화 버튼이 모든 선택을 제거하는지 확인
- [x] 반응형 디자인이 유지되는지 확인

---

### ☑️ Phase 4: 도시 카드 구조 변경 및 가짜 데이터 업데이트

**목표**: 도시 카드에 새로운 필터 정보(예산, 지역, 환경, 최고 계절)를 Key-Value 형태로 표시하고 실제 도시별 특성에 맞는 가짜 데이터로 업데이트

#### 수정/개선 기능
- [x] PopularCities.tsx의 도시 데이터 구조 변경
- [x] 각 도시에 budget, region, environment, bestSeason 필드 추가
- [x] 서울 강남구: 수도권, 도심선호, 200만원 이상, 봄/가을
- [x] 제주 제주시: 제주도, 자연친화, 100~200만원, 봄/여름
- [x] 부산 해운대구: 경상도, 자연친화, 100~200만원, 여름
- [x] 강릉시: 강원도, 자연친화, 100만원, 여름
- [x] 대전 유성구: 충청도, 코워킹 필수, 100만원, 가을
- [x] 기존 nomads, internet 정보 제거하고 새 필터 정보로 교체
- [x] Key-Value 형태의 UI 컴포넌트 구현

#### 검증/확인 기능
- [x] 모든 도시 카드에 4개 필터 정보가 올바르게 표시되는지 확인
- [x] Key-Value 형태의 정보가 읽기 쉽게 정렬되어 있는지 확인
- [x] 각 도시별 특성이 현실적으로 설정되어 있는지 확인
- [x] 카드 레이아웃이 새로운 정보와 잘 맞는지 확인
- [x] 반응형 디자인이 유지되는지 확인

## 📝 주요 참고사항

- 각 Phase는 독립적으로 실행 가능하며, 이전 Phase의 완료 없이도 해당 Phase 작업 시작 가능
- 데이터베이스는 사용하지 않고 가짜 데이터로 진행
- 기능 구현이 아닌 단계별 계획 수립이 목적
- 각 단계별로 명확한 체크리스트와 검증 기준 제공하여 효과적인 작업 진행 지원
